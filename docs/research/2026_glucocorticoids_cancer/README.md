# 糖皮质激素与肿瘤：方法准备

检索截至 **2026-10-19**。本轮收集方法、论文和可追溯代码资源；数据库选型、数据获取、正式 protocol 与真实分析在后续进行。

这类论文通常称为**基于公共数据库的观察性流行病学研究 / 二次数据分析**；药物主题属于**药物流行病学**。NHANES 常见复杂抽样横断面分析，链接死亡后可分析死亡随访；CHARLS 多波次可做纵向队列。与外部 GWAS/MR 联合可称“观察性与遗传流行病学联合研究”，各部分的暴露、结局与估计目标分别定义。

## 按需读取

- `observational_literature.md` / `observational_papers.json`：2026 NHANES/CHARLS 方法论文，附单列的 2024 直接先例、逐篇方法与读取范围。
- `mr_gwas_literature.md` / `mr_gwas_papers.json`：2026 MR/GWAS 应用和方法；预印本、仅摘要和正式文章分别标记。
- `methods.json` / `METHODS.md`：方法 → 论文 → GitHub → 本库模块与实现状态。
- `github_sources.json`：上游仓库、核查日期、commit、许可与来源位置。`reference_only` 表示只完成资源登记。
- `validation.json`：本次接口与索引检查；没有真实数据结论。

检索为有目的的方法采样，并非系统综述或全年穷尽清单。“所有方法”在本目录中指已纳入论文提取到的方法及本课题预先需要的设计、分析与诊断环节；不能把未知方法或未公开代码写成已收集。

## 课题边界与直接先例

2024 年已发表 [19 类药物使用、常见癌症与 NHANES+MR 研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10940964/)，包括糖皮质激素。2026 年还有 [糖皮质激素相关基因与 NSCLC 的 MR/多组学研究](https://doi.org/10.1038/s41698-026-01421-1)。前者研究用药，后者研究基因表达相关遗传工具；均需精读，笼统组合数据库与 MR 不足以确定研究增量。

“使用”“长期使用”“高累积剂量”“无适应证/不适当使用”分别需要相应信息。内源皮质醇、用药遗传倾向、NR3C1 等基因 cis 表达工具代表不同估计目标，均不能自动表示外源用药滥用。NHANES 横断面癌症史、随访癌症死亡、CHARLS 随访自报新发癌症也分别对应不同结局。

以 [NHANES 2017–2018 处方药 codebook](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/RXQ_RX_J.htm) 为例，过去 30 天用药与自报已用时长可以核实，公开表没有每日剂量字段。这里只作暴露定义的方法边界提示；尚未做跨数据库逐波次选型。

## 推荐组合次序

1. 定义目标人群、暴露、比较组、时间零点、潜伏期、癌种与估计目标；绘制适应证/混杂 DAG。
2. 观察性模块：清洗与纳排 → 抽样设计/纵向结构 → 描述 → 主模型 → 缺失与非线性 → 亚组/交互 → 稳健性与偏倚分析。
3. 遗传模块：暴露语义与 GWAS 审计 → 工具强度与 LD → harmonisation → MR/敏感性 → 全区域定位/共定位 → 外部复核与多重检验。
4. 预测 ML、中介、组学与通路只在回答独立问题时增加；不是每篇论文都应把全部模块运行一遍。
